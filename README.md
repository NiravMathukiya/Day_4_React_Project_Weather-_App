# ⛅ Weather App  

A simple and interactive **Weather App** built with **React.js** that fetches real-time weather data using an external API. The app provides users with weather conditions, temperature, humidity, and more for any searched location.  

## 🛠 Tech Stack  

- **Frontend:** React.js, Tailwind CSS  
- **API:** OpenWeatherMap API  
- **State Management:** React Hooks  

## 🚀 Features  

- ✅ **Search for real-time weather data**  
- ✅ **Displays temperature, humidity, and weather conditions**  
- ✅ **Dynamic background based on weather**  
- ✅ **Dark/Light mode support**  
- ✅ **Responsive design for mobile and desktop**

## 🌦 How to Use  

1. **Enter a city name** in the search bar.  
2. **Click the search button** to fetch the latest weather data.  
3. **View real-time weather details** including temperature, humidity, and conditions.  
4. **Switch themes** between dark and light mode.

## 📦 Installation (Run Locally)  

### 1️⃣ Clone the Repository  

```sh  
git clone https://github.com/yourusername/weather-app.git  
cd weather-app  
```  

### 2️⃣ Install Dependencies  
```bash  
npm install  
```  

### 3️⃣ Run the Development Server  
```bash  
npm run dev  
```  
The app will run on **http://localhost:5173**
